슬라이드 하나는 태그 하나

<slide id="budget" label="예산" section="직접 조작" footer>
  <notes>슬라이더를 움직여 보세요.</notes>
  <h2>이 슬라이드를 옮긴다면</h2>
  <input data-control="count" type="range">
  <script type="text/slide">
    input.addEventListener("input", () => slide.set({ count: +input.value }));
    slide.onUpdate((values) => { /* 화면은 여기서만 그린다 */ });
  </script>
</slide>
 가로 네 칸 단계 슬라이드. 칸마다 제목 한 줄, 설명 두 줄 정도가 적당하다. 샘플 · 단계

덱을 만드는 순서

  1. 템플릿 복사assets/template.html 을 초안 폴더에 둔다.
  2. 슬라이드 쓰기slide 태그에 마크업과 발표 노트를 채운다.
  3. 조작 붙이기필요한 슬라이드에만 text/slide 스크립트를 넣는다.
  4. 퍼블리시받은 주소를 data-url 에 적고 한 번 더 올린다.
 버튼으로 고르는 조작 슬라이드. 발표자가 고르면 청중 창에도 같은 답이 열린다. 샘플 · 퀴즈
